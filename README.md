# timing-huatai: 华泰金工 10 因子技术打分择时系统复现

本项目严格复现华泰证券金融工程深度研究报告**《A股择时之技术打分体系（2025-12-26）》**。系统涵盖 5 个技术维度、10 个精选底层技术观测指标，构建多空双向均值技术打分引擎，实现全市场与 11 大主流宽基指数的端到端量化择时回测与可视化。

详细架构分析与冷峻量化数据报告参见 [SYSTEM_OVERVIEW_AND_CONCLUSIONS.md](SYSTEM_OVERVIEW_AND_CONCLUSIONS.md)。

## 2. 综合打分与双版本信号对比

- **信号 1（全量 10 因子，阈值 $\pm 0.33$）**：
  - 10 因子等权均值打分落入 $[-1, +1]$。
  - 分段阈值：分值 $> 0.33$ 开多 (+1)，$< -0.33$ 开空 (-1)，其余中性观望 (0)。
  - 中性观望日占比达 57.8%，最大回撤较买入持有基准收窄 50.6%（-27.63% vs -55.99%）。
- **信号 2（精简 6 因子，阈值 0）**：
  - 剔除量价 4 因子，仅保留趋势、波动、拥挤 6 因子。
  - 阈值放宽至 0：分值 $> 0$ 开多 (+1)，$< 0$ 开空 (-1)。
  - 交易机会大幅增加，年化收益放大至 7.19%（基准 2.54%）。

## 5. 快速启动与测试

### 环境依赖
```bash
pip install -e .
# 或直接安装基础依赖
pip install numpy pandas pyarrow matplotlib psutil pytest
```

### 运行全流程回测
```bash
python run_huatai_10factors.py
```
*全流程端到端执行耗时仅约 2.3 秒，内存峰值约 246 MB。*

### 执行测试套件
```bash
pytest tests/
```
*包含 6 个测试套件，全面覆盖数据对齐、因子边界、打分映射、单指标回测与多宽基泛化。*
